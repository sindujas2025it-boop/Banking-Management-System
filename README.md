Banking Management System Using Java and MySQL

Project Description

This project is a console-based Banking Management System developed using Java and MySQL. It demonstrates Object-Oriented Programming (OOP) concepts and database connectivity using JDBC.

Features

- Account management
- Savings and current account classes
- MySQL database connectivity
- Database operations using Java

Technologies Used

- Java
- MySQL
- JDBC
- MySQL Connector/J

Team Project

Integrated OOP and DBMS project.

How to Run

1. Install Java JDK and MySQL.
2. Create the required database and tables in MySQL.
3. Configure the database credentials in "DBConnection.java".
4. Add the MySQL Connector/J library to the Java classpath.
5. Compile and run "BankApp.java".
